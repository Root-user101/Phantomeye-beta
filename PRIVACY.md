# Privacy Information for Beta Testers

## Read this before installing

PhantomEye is a security application whose features may require sensitive Android permissions, including camera access and, for some features, location access. The exact permissions and data flows can vary by app version and enabled features.

**This document is not a substitute for a verified, version-specific privacy policy.** Before any beta APK is published, the developer must document exactly what information that build accesses, stores, uploads, shares, and deletes.

## Before a beta release is available

No beta APK is currently published in this repository. Do not install a test build until its release notes and complete privacy disclosures are available.

## Permission transparency

For each release, the developer should explain:

- Which permissions are requested and why.
- When the camera or location is accessed.
- Whether images, location, or event metadata are stored locally.
- Whether any data is uploaded to Google Drive or another service.
- How long data is retained and how testers can delete it.
- Whether analytics, crash reporting, or third-party SDKs transmit data.

Do not assume that data stays on the device merely because a feature is described as local.

## Tester guidance

- Grant only permissions you understand and are comfortable with.
- Do not test in private spaces or situations where recording would violate another person's privacy or consent.
- Do not submit personal photos, camera captures, location history, passwords, OTPs, or private messages to the developer.
- Stop testing and uninstall the app if you are uncomfortable with its behavior.
- Report unexpected permission prompts or unexpected data transfers before continuing to use the beta.
