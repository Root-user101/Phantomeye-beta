# PhantomEye Beta Testing

Official coordination hub for PhantomEye Android beta testing.

PhantomEye is an Android security application. This repository documents beta releases, test procedures, known issues, and reliability findings across Android devices.

## Testing objective

Investigate whether PhantomEye remains operational during normal background use, and identify interruptions associated with Android, manufacturer battery management, app crashes, or other causes.

Devices of interest include Vivo, Xiaomi/Redmi/POCO, OPPO/Realme, Samsung, and Motorola.

## Participate

1. Read [PRIVACY.md](PRIVACY.md) before installing anything.
2. Read the [TESTING-GUIDE.md](TESTING-GUIDE.md).
3. Install only a beta APK linked from an official release in this repository.
4. Follow the test steps and submit a report using the template in the guide.

**No beta APK is published yet.** Do not install APKs sent through unofficial messages.

## Tester appreciation

The first five testers who provide useful, complete reports are eligible for free lifetime PhantomEye Pro. Reports are reviewed by the developer; submitting a report does not automatically guarantee eligibility. No purchase is required.

## Safety

Beta software can contain bugs and may behave differently across devices. Participation is voluntary. Stop testing and uninstall the app whenever you wish. Do not submit passwords, private messages, personal photos, precise home addresses, or other sensitive information in a report.
