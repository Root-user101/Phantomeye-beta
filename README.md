# PhantomEye Beta Testing

Welcome! This page is for people who want to try the PhantomEye Android app before its public release and help us test it on different phones.

You do **not** need to know programming or use a computer to install the app. You can download and install it directly on an Android phone.

## Download PhantomEye Beta (Android)

**Important: There is currently no beta APK published.** The steps below will work after an official beta release is available. Please do not download APK files sent through unofficial messages or websites.

1. Open the official **[PhantomEye Beta Releases page](https://github.com/Root-user101/Phantomeye-beta/releases)** on your Android phone.
2. Open the newest release at the top of the page.
3. Scroll down to the **Assets** section.
4. Tap the file ending in **.apk** to download it. If GitHub shows a file named **Source code**, do not download that. It is not the Android app.
5. When the download finishes, open your phone's **Downloads** notification or open the **Files / File Manager** app and tap the downloaded APK.
6. If Android asks for permission to install apps from your browser or file manager, allow it for that app only, then return and tap **Install**.
7. Wait for installation to finish, then tap **Open**.

The exact wording of Android prompts may differ between phone brands. Only install the APK attached to a release on the official link above. If there is no release, or no APK file under **Assets**, wait. Do not install anything else.

## Before you install

1. Read [Privacy Information](PRIVACY.md) so you understand the permissions and data handling.
2. Read the [Testing Guide](TESTING-GUIDE.md).
3. Check the release notes for the version and any known issues.
4. Install only the APK attached to an official release in this repository.

## How to help test

After an official release is available, follow the instructions in the [Testing Guide](TESTING-GUIDE.md). You can help by using the app normally and reporting whether it continues to work in the background.

You can send a report even if you are not technical. Just describe:
- Your phone brand and model.
- Your Android version.
- How long you tested the app.
- What worked, what stopped working, and when you noticed it.

Please do not include passwords, OTPs, private messages, personal photos, precise home addresses, or other sensitive information in a report.

## Tester appreciation

The first five testers who provide useful, complete reports are eligible for free lifetime PhantomEye Pro. Reports are reviewed by the developer. Sending a report does not automatically guarantee eligibility. No purchase is required.
